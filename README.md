# the-calculator
This is the final required project of The Foundations Course from The Odin Project.

## Running it locally

Open `index.html` in a browser, or run a local static server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/`.

## How it works

Type a calculation into the terminal prompt and press `=` to receive the result. You can write a direct equation like `12 / (2 + 4)` or include the equation inside a sentence like `what is 12 / (2 + 4)`.
